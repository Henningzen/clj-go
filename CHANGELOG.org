* Change Log
  All notable changes to this project will be documented in this file.

** [Unreleased]
*** Feature: - Dynamic grid size:
               - clj-go.engine, clj-go.board, clj-bo.utilities, dev namespaces
                 now supports a configurable grid size, set in config.clj
               - The grid sizes are invariants of either 9x9, 13x13 or 19x19
               - (All tests are updated to support grid-size)
               - utilities.terminal-board major refactoring
             - Dev and user namespaces are properly functional, with proper
	       tooling for interaction between Graphics board game state and
	       REPL.
*** Changed: - Upgrade to Clojure 1.12.5
             - clj-go.board minor refactorings.
*** Fixed:   - Broken changelog
*** Removed:

** [0.1.2] - 2026-05-13

    - Initial tests.
    - Migrate to Eclipse Public License 2.0.
    - Migrate to proper namespace structure 'jansenh.clj-go.core'.
    - Introduce dedicated namespace 'dev/user' for REPL development.

** [0.1.0] - 2025-03-13
*** Added
    - Files from the deps-new template.
